# Fashion-Cube

A modern e-commerce web application built with **React.js**, **Redux**, **Axios**, and **Sass**, designed to deliver a seamless online shopping experience. The application allows users to browse products, explore categories, manage their shopping cart, and authenticate securely.

## 🚀 Features

* Product Listing Page
* Product Detail View
* Category-Based Product Filtering
* Recommended Products Section
* Shopping Cart Management
* User Authentication (Login/Register)
* Responsive User Interface
* Centralized State Management with Redux
* API Integration using Axios
* Reusable React Components
* Modern React Hooks Architecture

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/quintuslabs/fashion-cube.git
cd fashion-cube
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm start
```

### Build for Production

```bash
npm run build
```
